# AGENTS.md — Personal Blog Lite

## Project Overview

Personal blog with public (read) and admin (CRUD) sections. No Spring, no framework — manual DI from `main()`.

**Stack:** Java 21, Vaadin 25.1 (Flow), Jetty embedded via vaadin-boot 13.6, MariaDB, jOOQ 3.21, Flyway 12, CommonMark 0.27, Logback 1.5, Gradle (Groovy DSL).

## Build & Run Commands

```bash
# Run app (dev mode, needs MariaDB running)
./gradlew run

# Run in production mode
./gradlew clean build -Pvaadin.productionMode

# Run tests
./gradlew test

# Run a single test class
./gradlew test --tests "io.vekzzdev.service.ArticleServiceTest"

# Run a single test method
./gradlew test --tests "io.vekzzdev.service.ArticleServiceTest.shouldFindAllArticles"

# Generate jOOQ sources (requires MariaDB running)
./gradlew jooqCodegen

# Check dependency tree
./gradlew dependencies
```

## Code Style

### Java

- **Java 21** — use records, sealed classes, text blocks, pattern matching where appropriate
- **Package:** `io.vekzzdev` (lowercase, no hyphens)
- **Naming:**
  - Classes: `PascalCase` — `ArticleService`, `HomeView`, `DashboardView`
  - Methods/fields: `camelCase` — `findAll()`, `articleTitle`
  - Constants: `UPPER_SNAKE_CASE` — `MAX_TITLE_LENGTH`
  - Tests: `shouldDoSomethingWhenCondition` — `shouldThrowWhenTitleIsNull`

### Imports

- Order: `java.*` → blank line → `jakarta.*` → blank line → `com.vaadin.*` → blank line → `io.vekzzdev.*` → blank line → `org.*` (jOOQ, Flyway, etc.)
- No wildcard imports (`import foo.bar.*`)
- Static imports only for `assertThat`, `Assertions.*`, jOOQ field references

### Types

- Prefer `Optional<T>` over `null` for service return types
- Use `Long` (not `long`) for IDs — database-generated
- Use `LocalDateTime` for timestamps
- jOOQ generated POJOs and Records in `io.vekzzdev.generated.jooq` — NEVER edit these
- Use SLF4J `Logger` (never `System.out.println`): `private static final Logger log = LoggerFactory.getLogger(MyClass.class);`

### Error Handling

- Service layer: catch checked exceptions, wrap in unchecked (`RuntimeException`) with cause
- Use `NoSuchElementException` for "not found" cases
- Always log at ERROR level with context before rethrowing
- Views: try-catch in event handlers, show user-friendly message via `Notification.show()`
- Never swallow exceptions silently

### Vaadin Views

- One route per view, annotated with `@Route("path")`
- `@RouteScope` for admin views, no scope for public views
- Views extend `VerticalLayout` (default) unless layout demands otherwise
- Use `@PageTitle` for browser tab title
- Keep view logic thin — delegate to services

### Flyway Migrations

- File naming: `V{N}__description.sql` (double underscore, sequential number)
- Always `NOT NULL` columns unless there's a deliberate reason
- Include `created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP` on all tables
- Migrations are immutable once merged — never edit, always add a new one

### Testing

- JUnit 6 (`@Test`, `@BeforeEach`, `@DisplayName`)
- AssertJ for assertions (`assertThat(result).isNotNull()`)
- Test class mirrors source path: `src/test/java/io/vekzzdev/service/ArticleServiceTest.java`
- Unit tests: no DB, no server — mock jOOQ DSLContext
- Integration tests: testcontainers or real MariaDB, not H2
