# AGENTS.md — Personal Blog Lite

## Project Overview

Personal blog with public (read) and admin (CRUD) sections. No Spring, no framework — manual DI from `main()`.

**Stack:** Java 21, Vaadin 25.1 (Flow), Jetty embedded via vaadin-boot 13.6, MariaDB, jOOQ 3.21, Flyway 12, CommonMark 0.27, jsoup 1.22 (HTML sanitization), Logback 1.5, Gradle (Groovy DSL).

## Build & Run Commands

```bash
# Start MariaDB (required for dev)
docker compose up -d db

# Run app (dev mode)
./gradlew run

# Run in production mode
./gradlew clean build -Pvaadin.productionMode

# Run all tests
./gradlew test

# Run a single test class (use FULLY-QUALIFIED name)
./gradlew test --tests "io.vekzzdev.personal_blog_lite.repository.jooq.JooqPostRepositoryTest"
./gradlew test --tests "io.vekzzdev.personal_blog_lite.service.PostServiceTest"
./gradlew test --tests "io.vekzzdev.personal_blog_lite.service.MarkdownServiceTest"

# Run a single test method
./gradlew test --tests "io.vekzzdev.personal_blog_lite.service.PostServiceTest.createPost*"

# Generate jOOQ sources (requires MariaDB running)
./gradlew jooqCodegen

# Check dependency tree
./gradlew dependencies
```

## Code Style

### Java

- **Java 21** — use records (only for immutable DTOs), sealed classes, text blocks, pattern matching where appropriate
- **Package:** `io.vekzzdev.personal_blog_lite` (use this exact package, not shortened)
- **Naming:**
  - Classes: `PascalCase` — `PostService`, `HomeView`, `MarkdownService`
  - Methods/fields: `camelCase` — `findAll()`, `postTitle`
  - Constants: `UPPER_SNAKE_CASE` — `MAX_TITLE_LENGTH`
  - Tests: `shouldDoSomethingWhenCondition` — `shouldThrowPostNotFoundExceptionWhenIdNotFound`

### Imports

- Order: `java.*` → blank line → `jakarta.*` → blank line → `com.vaadin.*` → blank line → `io.vekzzdev.*` → blank line → `org.*` (jOOQ, Flyway, Mockito, AssertJ)
- No wildcard imports (`import foo.bar.*`)
- Static imports for: `assertThat`, `Assertions.*`, `mock`, `when`, `verify` (Mockito), jOOQ field references

### Types

- Prefer `Optional<T>` over `null` for service return types (except void methods)
- Use `Integer` (not `int`) for IDs — database-generated, can be null before insert
- Use `LocalDateTime` for timestamps
- **Domain Models:** Use mutable POJOs (classes with getters/setters), NOT records for entities that jOOQ maps
- jOOQ generated code in `io.vekzzdev.generated.jooq` — NEVER edit these
- Use SLF4J `Logger` (never `System.out.println`): `private static final Logger log = LoggerFactory.getLogger(MyClass.class);`

### Domain Model (Post Example)

```java
public class Post {

    private String title;
    private String content;
    private LocalDateTime createdAt;
    private LocalDateTime updatedAt;

    // Constructors, getters, setters
    // equals(), hashCode(), toString() — REQUIRED for value comparison

```

### Error Handling

- **Domain Exceptions:** All exceptions extend `DomainException` (abstract RuntimeException)
- Service layer: catch checked exceptions, wrap in domain exception with cause
- Use specific exceptions: `PostNotFoundException`, `PostCreationException`, `PostUpdatingException`, `PostDeletingException`, `PostRenderingException`
- Always log at ERROR level with context before rethrowing
- Views: try-catch in event handlers, show user-friendly message via `Notification.show()`
- **Never swallow exceptions silently** — always propagate or log with context

### Vaadin Views

- One route per view, annotated with `@Route("path")`
- `@RouteScope` for admin views, no scope for public views
- Views extend `VerticalLayout` (default) unless layout demands otherwise
- Use `@PageTitle` for browser tab title
- Keep view logic thin — delegate to services

### Flyway Migrations

- File naming: `V{N}__description.sql` (double underscore, sequential number)
- Always `NOT NULL` columns unless there's a deliberate reason
- Include `created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP` on all tables
- Migrations are immutable once merged — never edit, always add a new one

## Testing

### Framework Stack
- **JUnit 5** (Jupiter) — `@Test`, `@BeforeEach`, `@DisplayName`, `@Nested`
- **AssertJ** — fluent assertions (`assertThat(result).isNotNull()`)
- **Mockito** — mocking with `@Mock`, `@InjectMocks`, `@ExtendWith(MockitoExtension.class)`

### Test Organization

```
src/test/java/io/vekzzdev/personal_blog_lite/
├── service/
│   ├── PostServiceTest.java         # Unit tests with Mockito
│   └── MarkdownServiceTest.java    # Unit tests, no mocks needed
└── repository/jooq/
    └── JooqPostRepositoryTest.java # Unit tests with MockDataProvider
```

### Unit Test Guidelines

- **Service tests:** Use Mockito to mock repository and dependencies
- **Repository tests:** Use MockDataProvider to mock jOOQ DSLContext
- **Test naming:** `methodName_should_expectedBehavior_when_scenario`
- **Use `@Nested`** for grouping related tests by method
- **Use `@DisplayName`** for human-readable test names
- **AssertJ assertions:** Always use `assertThat` for readable failures
- **Never test implementation details** — test behavior, not internal state

### Example Service Test

```java
@ExtendWith(MockitoExtension.class)
class PostServiceTest {
    @Mock private PostRepository postRepository;
    @InjectMocks private PostService postService;

    @Test
    @DisplayName("should throw PostNotFoundException when id not found")
    void shouldThrowPostNotFoundException_whenIdNotFound() {
        when(postRepository.findById(999)).thenReturn(Optional.empty());

        assertThatThrownBy(() -> postService.getPostById(999))
                .isInstanceOf(PostNotFoundException.class);
    }
}
```
